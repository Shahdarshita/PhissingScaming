# Contributing to PhissingScaming

This project is a college-level demonstration for a simple awareness-based Phishing, Scam & Fraud Detection application using ASP.NET Core MVC.

## Guidelines

- Keep code simple, readable and educational.
- Follow the .editorconfig rules (4-space indentation, UTF-8, PascalCase types/methods, underscore prefix for private fields).
- Do not add databases, external APIs, authentication, or background services.
- Do not introduce complex patterns or external frontend frameworks.

## How to build and run

1. Ensure .NET 8 SDK is installed.
2. From the project root run:

```sh
dotnet restore
dotnet run
```

3. Open the URL shown in the console (usually https://localhost:5001 or http://localhost:5000).

## Commit message style

Use concise messages, e.g.: `Add: DetectorController and View` or `Fix: image validation`.

## Reporting issues

Open an issue describing the problem and steps to reproduce.

## Code of Conduct

Be respectful and keep contributions focused on educational improvements.
